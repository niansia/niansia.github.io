Adversarial Lab

AI 安全線上試玩

在瀏覽器裡執行的對抗攻擊實驗場：畫一個或挑一個 MNIST 數字，在 L∞ 預算內用 FGSM、PGD 或指定目標的 PGD 攻擊 CNN，一步步看預測被翻轉，再透過梯度、轉移攻擊與輸入空間的決策地圖，和經過 PGD 對抗訓練的模型比較。攻擊所需的梯度用純 JavaScript 在訪客的 CPU 上計算。

打開互動式作品集 →在瀏覽器試試原始碼 ↗成果與方法 ↗

動手試試：騙過神經網路 — 對抗樣本實驗室 · FGSM／PGD 攻擊、決策地圖與對抗訓練模型，全部在你的 CPU 上執行。

佐證

在 2,000 張 MNIST 測試圖上以 PGD-40 評估：一般模型從 98.95% 的乾淨準確率在 ε = 0.2 時掉到 0.2%；對抗訓練模型在 ε = 0.2 仍有 92.2%、ε = 0.3 有 85.3%（乾淨準確率 97.92%）。附梯度遮蔽檢查（每個 ε 下 PGD 都比 FGSM 與轉移攻擊強）、與 PyTorch 誤差在 1e-8 內的 JavaScript 梯度，以及只用 CPU 的訓練與評估腳本。

這一頁的終端版有互動的部分：可以一步步播放的重播、滑桿和動畫。

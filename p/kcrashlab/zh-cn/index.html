KCrashLab

系统可靠性证据冻结

以模拟为优先的 Windows 驱动程序可靠性研究平台，用于执行确定且可复现的实验。系统会规范化案例、续跑中断的实验、最小化保留精确签名的触发条件，并生成可供独立验证的证据包。

SIMULATED — 以下的数字和动画，全部来自 KCrashLab repo 里记录的模拟实验：对象是合成的状态机，不是真实的系统崩溃，也不涉及任何第三方驱动程序。

架构：从一个输入到任何人都能验证的证据

  1. Case IR — 把每个输入规范化成有版本的 JSON，用内容的 SHA-256 当身份；格式不同、内容相同的输入只算一次。
  2. 确定性模拟 — 调度、变异和挑选全部由种子决定，同一个种子一定跑出一样的结果；中断后可以从 append-only journal 接着跑。
  3. 发现闭环 — 用精确签名识别失败，只在签名不变的前提下缩小触发条件，再从干净状态重放投票确认。
  4. 证据闭环 — 生成 SHA-256 清单和来源记录；验证器不只比对哈希，还交叉检查摘要、案例和报表是否一致。

Track B · 受控 Windows 实验室 — 另一条要手动开启的路径，只能对 repo 自己的测试驱动、在隔离的虚拟机里执行。一般命令永远不会选到它，目前也还没有实机结果。

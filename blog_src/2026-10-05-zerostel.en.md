[Zerostel](https://github.com/zerostel/zerostel) went public on October 5, with 0.1.1 on npm and a website at [zerostel.com](https://zerostel.com). It's a flight recorder and time machine for AI coding agents like Claude Code and Codex: every command an agent runs, every file it changes, and the time and tokens each step takes go on one timeline.

When the agent breaks something, `zerostel undo` puts the files back to before its last turn, and `zerostel rewind 0` goes all the way back to the start of the session. Changes made through shell commands such as `rm` or `git checkout` are included, and `zerostel ui` does the same in a local web page. Agents' own checkpoints differ a lot, and some don't track shell commands at all; Zerostel records every supported agent the same way and can export a report you can hand to someone else.

It supports Claude Code, Codex, Cursor, Gemini CLI, Antigravity, Copilot CLI and opencode, and `zerostel run` watches the files for anything else. Everything runs locally: nothing is uploaded, the project's own `.git` is never touched, and there are no runtime dependencies. Install with `npx zerostel install`, or run `npx zerostel demo` first: it builds a throwaway project, deletes a folder and undoes it, without touching any of your files.

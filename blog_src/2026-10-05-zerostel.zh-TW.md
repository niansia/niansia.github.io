[Zerostel](https://github.com/zerostel/zerostel) 10 月 5 日正式公開，npm 上是 0.1.1 版，官網在 [zerostel.com](https://zerostel.com)。它是給 Claude Code、Codex 這類 AI 寫程式工具用的行車紀錄器和時光機：agent 每一步跑了什麼指令、改了哪些檔案、花了多少時間和 token，都記在同一條時間軸上。

agent 把東西改壞時，`zerostel undo` 可以把檔案復原到上一輪之前，`zerostel rewind 0` 可以一路回到這次工作開始的時候，透過 `rm`、`git checkout` 這類 shell 指令造成的變化也包含在內，`zerostel ui` 則是同樣的功能做成本機網頁。各家 agent 內建的 checkpoint 做法差很多，有些不追蹤 shell 指令，Zerostel 對每個支援的 agent 都用同一套方式記錄，也能匯出一份報告給別人看。

目前支援 Claude Code、Codex、Cursor、Gemini CLI、Antigravity、Copilot CLI 和 opencode，其他工具可以用 `zerostel run` 監看檔案。全部在本機執行、不上傳任何資料、不碰專案自己的 `.git`，執行時也不需要任何相依套件。安裝只要 `npx zerostel install`，想先看看效果可以跑 `npx zerostel demo`，它會建一個暫時的專案示範刪檔和復原，不會動到你自己的檔案。

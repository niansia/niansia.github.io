[Zerostel](https://github.com/zerostel/zerostel), a flight recorder and time machine for AI coding agents, went public on October 5 (0.1.1 on npm). Every step an agent like Claude Code or Codex takes, the commands, the files it changed, the time and the tokens, goes on one timeline, and when the agent breaks something a single command puts the files back, including ones deleted through the shell with `rm`.

![zerostel log shows an agent deleting src/legacy with rm -rf; zerostel undo brings the files back](img/zerostel-demo.png)

It supports Claude Code, Codex, Cursor, Gemini CLI, Antigravity, Copilot CLI and opencode, and `zerostel run` watches the files for anything else. Everything runs locally, it never touches the project's own `.git`, and it has no runtime dependencies. Install with `npx zerostel install`, or try `npx zerostel demo` first.

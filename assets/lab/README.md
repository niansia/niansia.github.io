# Website companion

`yuki-sprites.png` is original generated Japanese anime character artwork created for this portfolio. Four equal columns: idle, walking, happy, sleepy. Canvas: 1536 × 1024; each frame: 384 × 1024. The image has transparent background pixels. CSS selects a frame without downloading separate images. A small inset on the happy frame prevents a neighboring hand from bleeding across the cell boundary.

The earlier `research-lab` files belong to the previous design and are not used by the terminal desktop. The GitHub profile keeps its separate design.
